# Viajes

Sitio público con los itinerarios y las recomendaciones de los viajes en familia, publicado con GitHub Pages.

- `index.html`: lista de viajes
- `punta-cana/`: Punta Cana (portada, `zona.html`, `excursiones.html` y `estilo.css`)

**Este repositorio es público.** No subir nombres, números de vuelo, códigos de reserva,
direcciones de alojamiento, presupuesto ni fotos de la familia.
